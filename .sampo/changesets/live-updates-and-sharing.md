Follow the disk and the game like the original manager: the mod list refreshes by
itself when Steam adds, updates or removes mods, new saves appear in Continue, and a
running game is detected (Play queues a relaunch for when it closes, and the game can
be closed from the manager). Add the original's shareable mod-list text, a guided
search for the mod that causes a problem, and "Reinstall from Workshop" for broken
downloads.
