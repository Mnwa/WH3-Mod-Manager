## 0.2.0 — 2026-10-02

### Added

- [34d8de6](https://github.com/Mnwa/WH3-Mod-Manager/commit/34d8de67eca4dbbb80f6f50e8bd7aa0195f73b38) Add the native WH3 mod-management core: Steam/Data/Workshop scanning, Unicode search,

  versioned WHM1 binary format with atomic saves and a previous-generation backup.
